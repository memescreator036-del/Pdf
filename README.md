# DocForge MVP

A browser-based PDF and writing workspace starter.

## Included
- Responsive dashboard
- PDF upload
- PDF text extraction using PDF.js
- Saved recent PDF extractions in localStorage
- Writing editor with autosave
- Word count
- Copy extracted text
- Export extracted text and writing as `.txt`
- Responsive mobile layout

## Run
Open `index.html` in a modern browser, or deploy the folder to Netlify/Vercel.

## Important
This is an MVP. Files are stored only in the browser and are not yet uploaded to a server. A production version should add authentication, secure cloud storage, server-side processing, database records, rate limits, and privacy controls.
